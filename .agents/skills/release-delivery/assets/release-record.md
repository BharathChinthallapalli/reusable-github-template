# Release record

Copy for the selected project release. Unknowns remain unknown until verified.

| Field | Record |
| --- | --- |
| Scope and authority | Requested target/environment and applicable release gate |
| Identity | Code commit, version, dependency environment, configuration revision |
| Artifact | Build command, output location, digest, contents check |
| AI/data inputs if applicable | Model/prompt/corpus/evaluator identities and evaluation report |
| Evidence | Unit/integration/consumer checks, exact CI run, unresolved failures |
| Compatibility | API, configuration, data or migration impact |
| Rollout | Authorized action, readiness signals, responsible owner |
| Recovery | Known previous artifact and state-compatible rollback procedure |
| Observed outcome | Prepared/published/deployed/healthy, with supporting evidence |
