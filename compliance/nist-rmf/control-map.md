# NIST risk-management actions

Use AI RMF1.0 GOVERN/MAP/MEASURE/MANAGE and GenAIProfile AI600-1 (2024).
For each project, record exact applicable function/category/subcategory/action ID,
source section/version, risk context, artifact, measurement, owner and evidence.
Actions must be selected from the fetched text, not inferred IDs. This scaffold
does not claim a completed per-project profile or certification.
