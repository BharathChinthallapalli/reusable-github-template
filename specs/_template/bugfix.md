# Bug specification

## Defect
Observed behavior, minimal inert reproduction, affected versions and evidence.

## Expected behavior
Requirement IDs and EARS criteria describing correct behavior.

## Unchanged behavior
Compatibility guarantees and regression cases that must stay unchanged.

## Cause hypothesis
Evidence, alternatives and discriminating tests; no speculative root-cause claim.

## Verification
Failing regression first where safely reproducible; repair; rerun regression and
adjacent contracts; add an incident eval if AI behavior was involved.

Still produce design.md, tasks.md and requirement traceability. Native Kiro's
bugfix-only variant needs a separate adapter; do not silently bypass this gate.
